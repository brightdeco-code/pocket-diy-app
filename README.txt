Pocket DIY — app branding update

This ZIP updates the existing Cloudflare Pages project with the approved green/lime icon and iPhone home-screen branding. It also includes 1024px store artwork and a portrait splash-screen concept in /icons.

This is still a web app, not an iOS or Android native binary. App Store submission and in-app purchases are NOT implemented.

Deploy to existing Pocket DIY Cloudflare Pages project. Check homepage, bottom navigation, saved items and Add to Home Screen icon. On iPhone, an old installed shortcut may need removing and re-adding to refresh the icon.
